# HEPA-compatible HVAC filtration upgrade

An HVAC filtration upgrade belongs under this option only when the system can actually provide HEPA-level filtration consistent with the QoL proposition. Ordinary higher-efficiency filters should not automatically be treated as equivalent to HEPA filtration; compatibility, airflow, installation, and system performance remain product-level questions.
