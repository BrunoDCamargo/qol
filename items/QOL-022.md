# Outsource cleaning when it meaningfully saves unwanted time

Hiring cleaning help is a concrete way to buy back time when cleaning consumes time you would rather use elsewhere.

The cited experiment supports the broader time-saving purchase principle. It did not test cleaning services as a distinct intervention.
