# Make the bedroom sufficiently dark for sleep

When bedroom light is disruptive, reducing that exposure is a practical way to create a darker sleep environment.

The available cited evidence is indirect for the broad room-darkening proposition, so this item remains conditional and should not be read as proof that a particular darkness level is optimal for everyone.
