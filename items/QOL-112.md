# Investigate possible endometriosis when cyclical pain or related symptoms impair daily life

Cyclical pelvic, sexual, gastrointestinal, or urinary symptoms should not automatically be normalized when they repeatedly interfere with daily life.

The item is an assessment prompt because the symptom pattern has multiple possible causes and does not establish endometriosis by itself.
