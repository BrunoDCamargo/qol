# Quantify the annual time cost of commuting

Adding up recurring commute time turns an easy-to-ignore daily cost into a decision input that can be compared with work, transport, and housing alternatives.

Neither cited study tests annual commute accounting itself, so the assessment is an inference intended to make a recurring QoL trade-off visible rather than to prescribe a particular decision.
