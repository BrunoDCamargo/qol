# Remove nonessential badges, banners, and vibrations

Badges, banners, and vibrations are additional attention cues that can be reduced when they are not necessary.

The evidence directly tests disabling communication notifications, not every interface cue separately, so applying that principle to these cues is an inference intended to reduce recurring interruption friction.
