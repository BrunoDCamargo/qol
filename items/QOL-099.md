# Duplicate inexpensive frequently transported items when it reliably removes repeated friction

A second low-cost item can remove repeated packing, forgetting, searching, or setup when the same object is needed in stable recurring locations.

This is a practical inference from time-saving evidence and should be applied only when the recurring friction is real.
