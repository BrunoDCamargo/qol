# Design the food environment so preferred choices are easy defaults

Keeping preferred foods convenient and less-preferred defaults less automatic can reduce recurring decision friction around eating.

The cited sources support dietary patterns, not the environmental-design tactic itself, so this item is explicitly an inferred implementation rather than a directly tested intervention.
