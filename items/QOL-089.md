# Use activity self-monitoring when it helps sustain movement

Tracking can be useful when the main problem is consistency or lack of awareness of actual activity.

Use the smallest tracking method that changes behavior; if tracking becomes distracting, compulsive, or burdensome, it is no longer serving the intended purpose.
