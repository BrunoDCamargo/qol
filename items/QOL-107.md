# Use intensive multicomponent behavioral weight-loss interventions for obesity when indicated

When obesity is clinically relevant, structured treatment can combine dietary, activity, self-monitoring, and behavioral components rather than relying on one isolated instruction.

The item is about an evidence-based treatment class, not a requirement that every person use the same program or pursue the same target weight.
