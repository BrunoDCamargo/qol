# Treat sub-guideline amounts of physical activity as useful, not worthless

Physical-activity targets should not create an all-or-nothing threshold where movement below the guideline is treated as having no value.

This guardrail keeps behavior change aligned with guidance that some activity provides benefit while still recognizing additional benefit from meeting recommended amounts.
