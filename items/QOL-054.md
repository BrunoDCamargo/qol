# Use water or unsweetened drinks as default hydration

Using water or unsweetened drinks as the routine hydration default is compatible with both hydration and dietary guidance without requiring a fixed universal fluid volume.

The item is about the default beverage pattern, not a claim that every sweetened drink must be eliminated.
