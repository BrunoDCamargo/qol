# QoL Catalog

The catalog is an extensible map, not a permanent ranking. IDs are stable. Categories are flexible tags and may be combined freely. An item can belong to several categories, and new categories can be introduced without renumbering existing items.

`Evidence` describes confidence in the stated claim, not expected effect size for a particular person. `Conditional` means the item is useful only when the relevant symptom, exposure, condition, circumstance, or preference exists. Items marked `Inference` are practical extrapolations from a broader evidence base rather than interventions directly tested in the cited source.
